# 양수빈

사용자가 직접 쓰는 서비스를 만드는 개발자입니다. 기획부터 구현까지 혼자 완성한 서비스가 있고, 팀에서는 3D 화면과 AI 연동을 맡았습니다.

## 프로젝트

| 프로젝트 | 설명 | 기술 |
|---|---|---|
| [덕친소](https://github.com/viiin2/deokchinso_project) | 덕질 동행을 찾는 모임 웹 서비스. 기획, 디자인, 개발을 혼자 했습니다. | React, Express, SQLite, Supabase, OpenAI·Gemini API |
| [ST-ROOKIE](https://github.com/steel-rookie/ST-ROOKIE) | 제철 공정을 3D로 보고 AI 튜터에게 질문하며 배우는 교육 사이트. 팀 프로젝트에서 3D 화면과 AI 튜터 패널을 맡았습니다. | Three.js, JavaScript, Node.js |
| [STEEL MIND](https://github.com/steel-rookie/steel-mind) | 제철소 공정을 배우는 게임. POSCO K-뉴딜 해커톤 출품작입니다. | Unity, C#, Gemini API |
| [Claude Sidebar for Obsidian](https://github.com/viiin2/obsidian-claude-sidebar) | 옵시디언 사이드바에서 노트를 묻고 다듬고 데일리 노트를 정리하는 플러그인 | TypeScript |
| [동물 디저트 카페](https://github.com/viiin2/animal-kitchen) | 1~4명이 함께 하는 로블록스 협동 요리 게임 시제품 | Luau, Rojo |

## 기술

- **언어:** JavaScript, TypeScript, Python
- **프런트엔드:** React, Next.js, Three.js
- **서버·데이터:** Node.js, Express, SQLite, Supabase
- **AI:** OpenAI API, Gemini API, YOLOv8

## 연구와 교육

- 유해 조류 객체 탐지 연구로 학회 논문 3편을 발표했습니다(1저자 2편).
- 포스코 K 뉴딜 아카데미를 수료했습니다.
- 안동대학교 컴퓨터공학과를 졸업하고 영남대학교 AI/SW학과를 복수전공했습니다.
